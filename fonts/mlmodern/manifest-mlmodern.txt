This directory contains webfont conversions of the MLModern font family.

The following files are derived from the MLModern work:

  mlmodern-regular.woff2
  mlmodern-italic.woff2
  mlmodern-bold.woff2

Original work:
  MLModern (version 1.2) by B. Jackowski, J.M. Nowacki, and Daniel Benjamin Miller
  Distributed from CTAN: fonts/mlmodern
  License: LaTeX Project Public License 1.3c or later (see LICENSE in this directory).

These WOFF2 files are Compiled Works generated from an unmodified copy of MLModern.
No changes were made to the design of the fonts; only format conversion.
